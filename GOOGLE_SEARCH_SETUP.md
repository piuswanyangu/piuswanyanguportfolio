# Google Search Setup

Step-by-step guide to getting afrinexsolutions.co.ke into Google. Every step
needs your Google account or Cloudflare access, so none of them has been done
yet. Deploy the latest code to the VPS first, so Google sees the improved
titles, descriptions and structured data.

---

## 1. Why Search Console matters

Google discovers new sites slowly on its own. Google Search Console is
Google's free dashboard for site owners. It lets you:

- prove you own the site;
- hand Google your sitemap, the full list of pages to index;
- ask Google to index specific pages now;
- see which searches show your site, and how often people click; and
- get alerts about indexing errors, security issues and Core Web Vitals.

---

## 2. Verify ownership with a Domain property

A **Domain property** covers every version of the site: `https://`,
`http://`, `www` and the apex domain. It is verified with a DNS record.

1. Open <https://search.google.com/search-console> and sign in.
2. Click **Add property** and choose **Domain**, the left option.
3. Enter `afrinexsolutions.co.ke`, without `https://`, and click **Continue**.
4. Google shows a TXT record like
   `google-site-verification=AbC123...`. Click **Copy**.
5. In Cloudflare: `afrinexsolutions.co.ke` > **DNS** > **Records** >
   **Add record**:

   | Type | Name | Content | TTL |
   | --- | --- | --- | --- |
   | TXT | `@` | the copied `google-site-verification=...` value | Auto |

   This adds a record and changes no existing record. Leave the `A` records
   for `@` and `www` untouched.
6. Back in Search Console, click **Verify**. If it fails, wait 10 minutes and
   try again. Never delete the TXT record later, because Google rechecks it.

---

## 3. Submit the sitemap

1. In Search Console, open **Sitemaps** in the left menu.
2. Under **Add a new sitemap**, enter `sitemap.xml` and click **Submit**.
3. Status should become **Success** and show about 22 discovered pages.

**How it works:** the sitemap at `/sitemap.xml` is generated by
`src/app/sitemap.ts` from the same data the site uses, so new services,
projects or published articles appear in it automatically. Google reads it
periodically and queues each URL for crawling.

---

## 4. Request indexing for key pages

**URL inspection**, the search bar at the top of Search Console. Inspect each
URL below, then click **Request indexing**:

- `https://afrinexsolutions.co.ke/`
- `https://afrinexsolutions.co.ke/services`
- `https://afrinexsolutions.co.ke/about`
- `https://afrinexsolutions.co.ke/contact`
- the KRA PIN, KRA returns, SHA and eTIMS service pages

There is a daily limit of roughly 10 requests. The sitemap covers the rest.

**Verify:** after a few days, URL inspection should say **URL is on Google**,
and the **Pages** report should show indexed pages rising.

---

## 5. Test structured data

1. Open <https://search.google.com/test/rich-results>.
2. Test `https://afrinexsolutions.co.ke/services/kra-registration-assistance`.
   Use any service URL from the sitemap.
3. Expect **Breadcrumbs** and **Organization** as valid items. The Service
   data is valid schema.org, but Google has no special result design for it,
   so the test may not list it. For a full check, paste the URL into
   <https://validator.schema.org>.

## 6. Remove the duplicate Vercel copy

`https://piuswanyanguportfolio.vercel.app` still serves an old copy of the
site. Until it redeploys with the latest code, it tells Google it is the
original.

Choose one:

- **Recommended: delete it.** Vercel dashboard > the project > **Settings** >
  scroll to the bottom > **Delete Project**. The VPS is now your host.
- **Keep it, but neutralise it.** Push the latest code. If the Vercel project
  is connected to GitHub, it rebuilds automatically, and its pages then name
  `https://afrinexsolutions.co.ke` as canonical.

**Verify:**

```bash
curl -s https://piuswanyanguportfolio.vercel.app/ | grep canonical
```

The command returns nothing (deleted) or the afrinexsolutions.co.ke URL.

## 7. Optional: Bing and Google Analytics

- **Bing Webmaster Tools** (<https://www.bing.com/webmasters>) can import your
  verified Search Console property in one click. Bing also feeds DuckDuckGo
  and several AI search tools.
- **Google Analytics 4 is not installed, deliberately.** It would add
  third-party JavaScript and cookies, require a cookie notice, and require
  Privacy Policy changes. Search Console already shows searches, clicks and
  rankings without touching visitors' browsers. Revisit GA4 only if you need
  on-site behaviour data. If you do, Cloudflare Web Analytics is a lighter,
  cookie-free alternative.

## 8. What to expect, and when

| Timeframe | What you should see |
| --- | --- |
| Same day | Property verified, sitemap submitted |
| 2 to 14 days | Home and key pages indexed. A search for "Afrinex Solutions" finds the site. |
| 2 to 8 weeks | Impressions appear in the **Performance** report for service searches |
| Months | Ranking for competitive terms, driven by content, links and reviews |

Check **Performance** and **Pages** in Search Console once a week for the
first month, then monthly.
